# 🧫 mygameio

Agar.io-подобная игра с глубокими механиками: ловушки, способности, эволюция клетки, опасности на карте, события, контракты и изменяющийся мир.

Весь дизайн-план и статус реализации — в **[PLAN.md](PLAN.md)** (16/16 механик готово).

## 🚀 Как запустить

### Вариант 1 — просто открыть
Откройте `index.html` в любом современном браузере (Chrome/Edge/Firefox).

### Вариант 2 — локальный сервер (без SDK)
```powershell
# Windows (PowerShell):
powershell -ExecutionPolicy Bypass -File serve.ps1     # → http://localhost:8765

# или любой другой статический сервер:
npx serve .
python -m http.server 8765
```

### Вариант 3 — dev-режим Яндекс Игр (рекомендуется для подготовки к публикации)

Официальный npm-пакет [`@yandex-games/sdk-dev-proxy`](https://www.npmjs.com/package/@yandex-games/sdk-dev-proxy)
поднимает игру вместе с моком SDK Яндекс Игр (dev-окружение):

```powershell
npm install          # зависимости (уже в devDependencies)
npm run dev          # → https://localhost:8080 (dev-mode=true)
```

Скрипты в `package.json`:

| Скрипт | Что делает |
|--------|------------|
| `npm run dev` | Отдаёт папку игры + SDK-мок, `--dev-mode=true` |
| `npm run dev:prod` | То же, но без dev-флагов (prod-окружение) |
| `npm run dev:proxy` | Проксирует уже запущенный сервер `http://localhost:8765` |

> ⚠️ Прокси работает по **HTTPS с самоподписанным сертификатом**. При первом открытии
> браузер предупредит о сертификате — это ожидаемо для локальной разработки
> (на платформе Яндекс Игр сертификат валидный).

В dev-режиме `/sdk.js` отдаётся прокси, поэтому в игре доступны
`YaGames.init()`, `LoadingAPI.ready()`, `GameplayAPI`, события паузы,
реклама, сохранение рекорда и автоопределение языка — всё как на платформе.

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| Мышь | Движение клетки |
| Space | Быстрое разделение |
| Q / E / R / F / C / V | Способности: Рывок, Щит, Разделение, Поглощение, Телепорт, Заморозка |
| X | Призрачный режим |
| 1–6 | Ловушки: Шип, Клей, Мина, Сеть, Лужа, Фальшивая еда |
| 7–0 | Строительство: Стена, Барьер, Турель, Портал |
| P | Пауза |
| H | Справка по управлению |

## 🧠 Ключевая идея

Масса + энергия + ловушки — одна система:

- **Энергия растёт с массой** → больше возможностей для способностей.
- Решение каждый момент: **оставить массу себе** (стать сильнее), **потратить на ловушки** (контролировать территорию) или **на способности** (атаковать/убегать).
- **Разложение**: слишком большая клетка теряет массу без еды — огромные игроки вынуждены двигаться и охотиться.

## 📌 Этапы

- ✅ **Этап 1–4**: single-player со всеми 16 механиками (готово)
- ✅ **Интеграция Яндекс Игр**: SDK (ready/GameplayAPI/паузы), реклама, сохранение
  рекорда, локализация ru/en, dev-режим через `@yandex-games/sdk-dev-proxy`
- ⬜ **Этап 5**: мультиплеер — Node.js + WebSocket (серверная симуляция, авторитетный сервер, интерполяция клиента)

## 🌐 Соответствие требованиям Яндекс Игр

- **1.19** — SDK подключён по докам (`/sdk.js`), `LoadingAPI.ready()`, `GameplayAPI.start/stop`, обработчики `game_api_pause/resume`
- **1.9** — рекорд сохраняется (`ysdk.getPlayer().setData` + localStorage)
- **1.12 / 4.4 / 4.7** — межстраничная реклама при смерти с кулдауном 60 с, липкий баннер в меню, геймплей останавливается на время рекламы
- **2.14** — автоопределение языка через `ysdk.environment.i18n.lang` (ru/en, резервный набор Яндекса)
- **1.6.2.4** — управление не зависит от раскладки (`e.code`)
- **1.6.1.8 / 1.6.2.7** — запрет контекстного меню и выделения текста
- **1.21 / 1.22** — архив укладывается в 100 МБ, все имена файлов — ASCII
