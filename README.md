# 🧫 mygameio

Agar.io-подобная игра с глубокими механиками: ловушки, способности, эволюция клетки, опасности на карте, события, контракты и изменяющийся мир.

Весь дизайн-план и статус реализации — в **[PLAN.md](PLAN.md)** (16/16 механик готово).

## 🚀 Как запустить

### Вариант 1 — просто открыть
Откройте `index.html` в любом современном браузере (Chrome/Edge/Firefox).

### Вариант 2 — локальный сервер (рекомендуется)
```powershell
# Windows (PowerShell):
powershell -ExecutionPolicy Bypass -File serve.ps1     # → http://localhost:8765

# или любой другой статический сервер:
npx serve .
python -m http.server 8765
```

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| Мышь | Движение клетки |
| Space | Быстрое разделение |
| Q / E / R / F / C / V | Способности: Рывок, Щит, Разделение, Поглощение, Телепорт, Заморозка |
| X | Призрачный режим |
| 1–6 | Ловушки: Шип, Клей, Мина, Сеть, Лужа, Фальшивая еда |
| 7–0 | Строительство: Стена, Барьер, Турель, Портал |
| P | Пауза |
| H | Справка по управлению |

## 🧠 Ключевая идея

Масса + энергия + ловушки — одна система:

- **Энергия растёт с массой** → больше возможностей для способностей.
- Решение каждый момент: **оставить массу себе** (стать сильнее), **потратить на ловушки** (контролировать территорию) или **на способности** (атаковать/убегать).
- **Разложение**: слишком большая клетка теряет массу без еды — огромные игроки вынуждены двигаться и охотиться.
